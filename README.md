# Запасы корма для кота

Решение олимпиадного задания на C++: найти максимальное число дней, в течение которых кот сможет питаться без пополнения запасов, и выбрать оптимальный день начала.

## Условие задачи

Есть три вида корма:

- `a` порций рыбного корма;
- `b` порций рагу из кролика;
- `c` порций куриной отбивной.

Каждый день кот съедает одну порцию по расписанию:

| День недели | Корм |
| --- | --- |
| Понедельник | Рыбный корм |
| Вторник | Рагу из кролика |
| Среда | Куриная отбивная |
| Четверг | Рыбный корм |
| Пятница | Куриная отбивная |
| Суббота | Рагу из кролика |
| Воскресенье | Рыбный корм |

Расписание повторяется каждую неделю. Можно начать с любого дня недели. Если нужного корма на очередной день нет, питание по расписанию прекращается: заменить его другим кормом нельзя.

Нужно определить максимальную продолжительность питания и подходящий стартовый день. Если несколько дней дают одинаковый результат, программа выбирает первый по порядку от понедельника до воскресенья.

## Ввод и вывод

На вход подаются три неотрицательных целых числа `a b c`, разделённых пробелами или переводами строки.

Программа выводит две строки:

1. Максимальное число дней.
2. Название оптимального стартового дня на русском языке.

При некорректном вводе программа сообщает об ошибке и завершает работу с кодом `1`.

### Пример

Ввод:

```text
30 20 10
```

Вывод:

```text
39
суббота
```

Запасов хватает на пять полных недель — 35 дней. После них остаются 15 порций рыбы, 10 порций рагу и ни одной порции курицы. Если начать в субботу, можно прожить ещё четыре дня: субботу, воскресенье, понедельник и вторник. В среду потребуется курица, которой уже нет.

## Алгоритм решения

За любые семь последовательных дней расходуются три порции рыбы, две порции рагу и две порции курицы. Поэтому число полных недель не зависит от стартового дня:

```text
weeks = min(a / 3, b / 2, c / 2)
```

Деление целочисленное. Вычитаем корм, потраченный за эти недели:

```text
a -= weeks * 3
b -= weeks * 2
c -= weeks * 2
```

Затем перебираем все семь стартовых дней. Для каждого берём отдельную копию остатков и симулируем питание до первого дня, на который не хватает нужного корма. Добавляем самый длинный остаток к полным неделям:

```text
answer = weeks * 7 + best_days
```

После вычитания полных недель хотя бы одного вида корма не хватает на следующую неделю. Поэтому каждая симуляция охватывает не больше шести успешных дней, независимо от размера исходных запасов.

Сложность по времени — **O(1)**, дополнительная память — **O(1)**. Для запасов и итогового числа дней используется `long long`.

## Сборка и запуск

Нужен компилятор с поддержкой C++17, например `clang++` или `g++`.

```sh
clang++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o main
./main
```

После запуска введите три числа. В VS Code также настроена задача сборки активного файла через `clang++`.
